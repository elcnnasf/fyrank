## The thread running through all four

FL-01 audits my week and picks three tasks — one per band of the delegation framework. FL-02 to
FL-04 each take one of them and try to hit the success definition set in FL-01:

| Band | Target task | Picked up in |
|---|---|---|
| Delegate to AI, I review | Draft an SEO/GEO article from my outline | FL-02 |
| Collaborate with AI | Debug a failed crawl / production error | FL-03 |
| Fully automate | Weekly metrics report | FL-04 |

## Folder convention

```
FL-0X-<name>/
├── README.md      # brief, success definition, status
├── evidence/      # screenshots and artefacts for submission
└── results.md     # measured outcome vs. the success definition
```
